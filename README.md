# ระบบติดตามผลงานวิชาการ บัณฑิตวิทยาลัย มหาวิทยาลัยมหิดล (MUGR)

ระบบนี้ใช้กำกับ ติดตาม และตรวจรับรองผลงานวิชาการของอาจารย์ประจำหลักสูตร และใช้ตรวจคุณสมบัติ **บุคคลภายนอก (ผู้ทรงคุณวุฒิภายนอก)**
ของบัณฑิตวิทยาลัย มหาวิทยาลัยมหิดล (MUGR) โดยอ้างอิง
[ประกาศ ก.พ.อ. เรื่อง หลักเกณฑ์การพิจารณาวารสารทางวิชาการสำหรับการเผยแพร่ผลงานทางวิชาการ พ.ศ. 2562](https://www.ratchakitcha.soc.go.th/DATA/PDF/2562/E/151/T_0013.PDF)

### สมัครใช้งานด้วยอีเมลและการอนุมัติสิทธิ์
1. ผู้ใช้ใหม่เปิดหน้าเข้าสู่ระบบแล้วเลือกแท็บ **สมัครใช้งานด้วยอีเมล** กรอกอีเมล ชื่อ รหัสผ่าน (อย่างน้อย 8 ตัว) บทบาทที่ขอ และหลักสูตร
2. บัญชีจะอยู่ในสถานะ **รออนุมัติ** และยังเข้าสู่ระบบไม่ได้
3. Admin เห็นตัวเลขแจ้งเตือนที่เมนู **จัดการระบบ** และบนแดชบอร์ด จากนั้นไปที่ **จัดการระบบ > ผู้ใช้งาน > คำขอสมัครใช้งาน**
   - กด **อนุมัติ** แล้วกำหนดบทบาท หลักสูตร หรือผูกกับรายชื่ออาจารย์ ถ้าอีเมลตรงกับอีเมลในข้อมูลอาจารย์ ระบบจะเลือกให้อัตโนมัติ
   - กด **ไม่อนุมัติ** หากไม่ใช่ผู้มีสิทธิ์
4. ผู้ใช้เข้าสู่ระบบด้วย **อีเมล** และรหัสผ่านที่สมัครไว้
5. **Admin อัตโนมัติ:** อีเมลที่อยู่ในรายชื่อจะได้สิทธิ์ Admin ทันทีเมื่อสมัคร ตั้งได้ 2 ที่ ได้แก่ `ADMIN_EMAILS` ใน `Code.gs` (เช่น `var ADMIN_EMAILS = ['staff@mahidol.ac.th'];`) หรือ **จัดการระบบ > ตั้งค่าเกณฑ์ > อีเมลผู้ดูแลระบบ** ถ้ากำหนด `ADMIN_EMAILS` ก่อนรัน `setup` ระบบจะไม่สร้างบัญชี `admin` / `admin1234`
6. Admin ระงับบัญชีได้ที่ปุ่มแก้ไขผู้ใช้ > สถานะบัญชี > ระงับการใช้งาน

### 2. แดชบอร์ดและการแจ้งเตือนอัจฉริยะ
- การ์ดสรุป: หลักสูตร · อาจารย์ (จำนวนที่ผ่านเกณฑ์) · ผลงานที่นับได้ใน 5 ปี · ผลงานรอตรวจสอบ
- การแจ้งเตือน: 🔴 อาจารย์ไม่มีผลงานใน 5 ปี / ผลงานยังไม่ถึงเกณฑ์ · 🟠 ผลงานใกล้หมดอายุ (ตีพิมพ์ในปีแรกของรอบ 5 ปี จะไม่นับในปีถัดไป) · 🔵 ผลงานรอตรวจ · ผลงานถูกส่งกลับแก้ไข · ผลงานเกิน 5 ปี
- กราฟสัดส่วนผลงานตามฐานข้อมูล และค่าน้ำหนักเฉลี่ยรายหลักสูตร

### 3. เพิ่ม แก้ไข ลบ ผลงานวิชาการ
1. เมนู **ผลงานวิชาการ > เพิ่มผลงาน**
2. เลือกอาจารย์ ประเภทผลงาน และแหล่งเผยแพร่ ระบบแสดงค่าน้ำหนักและระดับตามประกาศ ก.พ.อ. ให้ทันที
3. กรอกปีที่ตีพิมพ์ จะกรอกเป็น พ.ศ. หรือ ค.ศ. ก็ได้ ถ้าเกิน 5 ปี ระบบจะเตือนว่าผลงานนั้นไม่นำมาคิดคะแนน
4. ใส่ลิงก์หลักฐานหรือ DOI แล้วบันทึก ผลงานจะอยู่ในสถานะ **รอตรวจสอบ**

### 4. การตรวจรับรองผลงาน (Verification Workflow)
`อาจารย์บันทึก → รอตรวจสอบ → ผู้ตรวจค้นในฐานข้อมูล → รับรองแล้ว (นับคะแนน) / ส่งกลับแก้ไข (พร้อมเหตุผล) → อาจารย์แก้ไข → รอตรวจสอบ`

ในหน้าตรวจรับรองมีลิงก์ค้นชื่อผู้แต่งใน Scopus, ThaiJO/TCI, Web of Science, PubMed, ERIC, Google Scholar และลิงก์ SJR สำหรับดู Quartile ผู้ตรวจแก้ประเภทฐานข้อมูลหรือ Quartile ได้ก่อนกดรับรอง

### 5. ตรวจคุณสมบัติบุคคลภายนอก (ผู้ทรงคุณวุฒิภายนอก)
1. เมนู **ตรวจคุณสมบัติบุคคลภายนอก > ตรวจบุคคลใหม่** แล้วกรอกชื่อไทยและอังกฤษ หน่วยงาน วุฒิ ตำแหน่งทางวิชาการ บทบาทที่เชิญ ระดับการสอบ (ป.โท/ป.เอก) และเกณฑ์ที่หลักสูตรใช้
2. กดลิงก์ **ค้นหาชื่อในฐานข้อมูล** (Scopus / ThaiJO / WoS / PubMed / ERIC / Scholar)
3. บันทึกผลงานที่พบทีละรายการ เลือกฐานข้อมูล แล้วติ๊ก **ยืนยันแล้ว** ระบบนับเฉพาะผลงานที่ยืนยันแล้ว
4. ระบบเทียบผลกับ **ทั้ง 3 เกณฑ์ (2548 / 2558 / 2565)** ในตารางเดียว แล้วสรุปว่าผ่านหรือไม่ผ่าน
5. กด **บันทึกผลการตรวจ** แล้ว **พิมพ์แบบตรวจสอบ** เป็น PDF ซึ่งมีช่องลงนาม

| คุณสมบัติ | เกณฑ์ 2548 | เกณฑ์ 2558 | เกณฑ์ 2565 |
|---|---|---|---|
| คุณวุฒิ (โท/เอก) | ป.เอกหรือเทียบเท่า หรือ ป.โท + ตำแหน่งไม่ต่ำกว่า รศ. | ป.เอกหรือเทียบเท่า | ป.เอกหรือเทียบเท่า |
| ผลงาน — ป.เอก | มีประสบการณ์ทำวิจัยที่ไม่ใช่ส่วนหนึ่งของการศึกษาเพื่อรับปริญญา | ระดับนานาชาติ 5 รายการ | ฐานข้อมูลที่ยอมรับ 10 รายการ |
| ผลงาน — ป.โท | มีประสบการณ์ทำวิจัยที่ไม่ใช่ส่วนหนึ่งของการศึกษาเพื่อรับปริญญา | ระดับชาติ 10 รายการ หรือนานาชาติ 5 รายการ | ฐานข้อมูลที่ยอมรับ 5 รายการ |

การนับในระบบ: **นานาชาติ** = Scopus, WoS (SCIE/SSCI/AHCI), PubMed, ERIC, MathSciNet, JSTOR, Project MUSE ·
**ชาติ** = TCI กลุ่ม 1–2 · **ฐานที่ยอมรับ** = ชาติ + นานาชาติ ตามประกาศ ก.พ.อ. 2562 ·
สำหรับเกณฑ์ 2558 แบบ ป.โท ระบบนับผลงานนานาชาติรวมในโควตาระดับชาติ 10 รายการด้วย ·
บุคคลภายนอกนับผลงานทั้งหมด ไม่จำกัดเฉพาะ 5 ปี

### 6. การจัดการข้อมูลอาจารย์และหลักสูตร
- Admin เพิ่มหลักสูตรและกำหนดระดับ (ตรี/โท/เอก) ซึ่งใช้กำหนดเกณฑ์ขั้นต่ำและค่าเป้าหมาย
- เพิ่มอาจารย์ กำหนดประเภท (ผู้รับผิดชอบหลักสูตร / ประจำหลักสูตร / ประจำ / พิเศษ) และใส่ชื่อภาษาอังกฤษเพื่อใช้ค้น Scopus/WoS
- สร้างบัญชีให้ประธานหลักสูตร (ผูกกับหลักสูตร) และอาจารย์ (ผูกกับรายชื่ออาจารย์) ที่ **จัดการระบบ > ผู้ใช้งาน**

### 7. การประเมินคุณภาพหลักสูตรและการออกรายงาน PDF
- **ร้อยละผลรวมถ่วงน้ำหนัก** = (ผลรวมค่าน้ำหนักผลงานที่รับรองแล้วของอาจารย์ผู้รับผิดชอบหลักสูตร ÷ จำนวนอาจารย์ผู้รับผิดชอบหลักสูตร) × 100
- **คะแนน** = (ร้อยละ ÷ ร้อยละเป้าหมาย) × 5 คะแนนสูงสุดคือ 5 ค่าเป้าหมายเริ่มต้นคือ ป.ตรี 20 · ป.โท 40 · ป.เอก 60
- เลือกได้ว่าจะคิดจากผลงานของปีประเมินเท่านั้น (ตามคู่มือ QA) หรือผลงานสะสม 5 ปี
- เมนู **รายงาน** มีรายงานรายหลักสูตร รายบุคคล ภาพรวมบัณฑิตวิทยาลัย และแบบตรวจสอบบุคคลภายนอก กด **พิมพ์ / บันทึก PDF** แล้วเลือก Save as PDF

### 9. คำถามที่พบบ่อย (FAQ)
- **ผลงานไม่ถูกนำมาคิดคะแนน** — ตรวจ 4 ข้อ:
  1. สถานะต้องเป็น "รับรองแล้ว"
  2. ปีที่ตีพิมพ์ต้องอยู่ในรอบ 5 ปีของปีประเมิน
  3. แหล่งเผยแพร่ต้องมีค่าน้ำหนักมากกว่า 0 (TCI 3 และวารสารนอกฐานได้ 0)
  4. อาจารย์ต้องเป็น "อาจารย์ผู้รับผิดชอบหลักสูตร" จึงจะถูกนับในตัวบ่งชี้ระดับหลักสูตร
- **สร้างข้อมูลเริ่มต้น** — ใช้ จัดการระบบ > ข้อมูล > โหลดข้อมูลตัวอย่าง หรือเริ่มเองตามลำดับ: หลักสูตร → อาจารย์ → บัญชีผู้ใช้ → ผลงาน
- **ย้ายข้อมูลระหว่างเครื่อง** — กด สำรองข้อมูล (JSON) ที่เครื่องเดิม แล้วกด กู้คืนข้อมูล ที่เครื่องใหม่
- **ลืมรหัสผ่าน admin** — ถ้าเก็บข้อมูลในเครื่อง ให้ลบคีย์ `mugr.data` ใน Local Storage (ข้อมูลจะหาย) · ถ้าใช้ Google Sheets ให้แก้ในชีต Users

1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล แล้วไปที่ **ส่วนขยาย > Apps Script**
2. ในไฟล์ `Code.gs` ลบโค้ดเดิมให้หมด แล้ววางโค้ดจาก [`apps-script/Code.gs`](apps-script/Code.gs)
3. สร้างไฟล์ HTML ให้ครบ **11 ไฟล์** โดยกด **+ > HTML** แล้วตั้งชื่อตามตาราง (ไม่ต้องพิมพ์ .html) จากนั้นวางเนื้อหาจากไฟล์ชื่อเดียวกันในโฟลเดอร์ [`apps-script/`](apps-script/)
   หน้าเว็บถูกแบ่งเป็นไฟล์ย่อยเพื่อให้คัดลอกได้ครบ และ `Code.gs` จะรวมไฟล์ให้เองตอนเปิดเว็บ

   | ชื่อไฟล์ใน Apps Script | เนื้อหา |
   |---|---|
   | `index` | โครงหน้าเว็บ |
   | `css` | ธีมสว่าง/มืด และ layout |
   | `criteria` | เกณฑ์ ก.พ.อ. 2562 ค่าน้ำหนัก และเกณฑ์ผู้ทรงคุณวุฒิภายนอก |
   | `app1` … `app8` | โค้ดการทำงานของระบบ (ต้องครบทั้ง 8 ไฟล์) |

4. บันทึก เลือกฟังก์ชัน `setup` แล้วกด **Run** หนึ่งครั้ง จากนั้นอนุญาตสิทธิ์ ระบบจะสร้างชีต Programs, Lecturers, Works, Users, Externals, Settings และบัญชี `admin` / `admin1234`
5. **Deploy > New deployment > Web app** ตั้ง Execute as: **Me** และ Who has access: **Anyone** (หรือ "Anyone within mahidol.ac.th" ถ้าต้องการให้เข้าได้เฉพาะคนในองค์กร)
6. เปิด URL ที่ลงท้ายด้วย `/exec` แล้วเข้าสู่ระบบด้วย `admin` จากนั้น **เปลี่ยนรหัสผ่านทันที**
7. ถ้าต้องการข้อมูลทดลอง ไปที่ จัดการระบบ > ข้อมูล > โหลดข้อมูลตัวอย่าง (ข้อมูลในชีตจะถูกแทนที่)

ทุกครั้งที่แก้โค้ด ให้ไปที่ **Deploy > Manage deployments > ✏ > Version: New version > Deploy** แล้ว URL จะยังเป็นอันเดิม

ไม่จำเป็นต้องแชร์ชีตเป็นแบบ "ทุกคนที่มีลิงก์" เพราะเว็บแอปทำงานด้วยสิทธิ์ของเจ้าของ ควรตั้งการแชร์ชีตเป็น **จำกัด**
เซิร์ฟเวอร์ตรวจสิทธิ์ซ้ำทุกคำขอ เช่น อาจารย์รับรองผลงานของตนเองไม่ได้ และประธานหลักสูตรแก้ได้เฉพาะหลักสูตรของตน รหัสผ่านเก็บเป็น SHA-256 hash

ถ้าโฮสต์หน้าเว็บแยกไว้ที่ GitHub Pages ก็ยังใช้ได้ ให้นำ URL `/exec` ไปใส่ที่ **จัดการระบบ > การเชื่อมต่อ**

> นักพัฒนา: เมื่อแก้ `index.html` หรือไฟล์ใน `assets/` ให้รัน `python3 tools/build_gas.py` เพื่อสร้างไฟล์ใน `apps-script/` ใหม่

## โครงสร้างไฟล์
```
index.html            หน้าเว็บหลัก
assets/styles.css     ธีม (สว่าง/มืด) และ layout responsive + รูปแบบการพิมพ์
assets/criteria.js    เกณฑ์ ก.พ.อ. 2562, ค่าน้ำหนัก, เกณฑ์ผู้ทรงคุณวุฒิภายนอก, FAQ, ลิงก์ฐานข้อมูล
assets/app.js         ตรรกะของระบบทั้งหมด
apps-script/Code.gs   ฝั่งเซิร์ฟเวอร์ Apps Script + Google Sheets
apps-script/*.html     หน้าเว็บสำหรับ Apps Script แบ่งเป็นไฟล์ย่อย (สร้างจาก tools/build_gas.py)
tools/build_gas.py     สคริปต์สร้างไฟล์ใน apps-script/
```

> สรุปเกณฑ์ในระบบจัดทำขึ้นเพื่อช่วยการตรวจสอบเท่านั้น ให้ยึดประกาศฉบับเต็มของ ก.พ.อ. และมหาวิทยาลัยเป็นหลัก
