# แบบสอบถาม SCB Business Anywhere → Google Sheets

| ไฟล์ | หน้าที่ |
|---|---|
| `Index.html` | หน้าแบบสอบถาม (ส่วนที่ 1–3) |
| `Code.gs` | Google Apps Script รับข้อมูลแล้วบันทึกลงชีต |

## วิธีติดตั้ง (ประมาณ 5 นาที)

1. สร้าง Google Sheets ใหม่ (เช่น "ผลแบบสอบถาม SCB")
2. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `Code.gs` ของโฟลเดอร์นี้
4. กดปุ่ม **+ > HTML** ตั้งชื่อไฟล์ว่า `Index` (ตัว I ใหญ่ ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาจาก `Index.html`
5. กดบันทึก จากนั้นเลือกฟังก์ชัน `testSave` แล้วกด **Run** → อนุญาตสิทธิ์ (Authorize) → ในชีตจะมีแท็บ `Responses` พร้อมหัวตารางและแถวทดสอบ 1 แถว (ลบแถวทดสอบได้)
6. **Deploy > New deployment** → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
7. กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) — ลิงก์นี้คือลิงก์แบบสอบถามที่ส่งให้ผู้ตอบได้ทันที

> แก้โค้ดภายหลัง ต้องไปที่ **Deploy > Manage deployments > แก้ไข (ดินสอ) > Version: New version** ไม่เช่นนั้นลิงก์เดิมยังใช้โค้ดเก่า

## ถ้าต้องการโฮสต์หน้าเว็บที่อื่น (เช่น GitHub Pages)

แก้ค่า `GAS_WEB_APP_URL` ใน `Index.html` เป็น Web app URL จากขั้นตอนที่ 7
หน้าเว็บจะส่งข้อมูลด้วย `fetch` ไปที่ `doPost` ใน `Code.gs`
