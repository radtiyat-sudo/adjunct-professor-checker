# แบบสอบถาม SCB Business Anywhere → Google Sheets

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าขอความยินยอม + แบบสอบถาม (ส่วนที่ 1–3) |
| `Code.gs` | Google Apps Script รับข้อมูลแล้วบันทึกลงชีต |

## วิธีติดตั้ง (ประมาณ 5 นาที)

1. สร้าง Google Sheets ใหม่ (เช่น "ผลแบบสอบถาม SCB")
2. ในชีต ไปที่เมนู **ส่วนขยาย (Extensions) > Apps Script**
3. ลบโค้ดเดิมในไฟล์ `Code.gs` แล้ววางเนื้อหาจาก `Code.gs` ของโฟลเดอร์นี้
4. กดปุ่ม **+ > HTML** ตั้งชื่อไฟล์ว่า `index` (ตัวพิมพ์เล็กทั้งหมด ไม่ต้องพิมพ์ .html) แล้ววางเนื้อหาจาก `index.html`
5. กดบันทึก จากนั้นเลือกฟังก์ชัน `testSave` แล้วกด **Run** → อนุญาตสิทธิ์ (Authorize) → ในชีตจะมีแท็บ `ผลแบบสอบถาม` พร้อมหัวตารางและแถวทดสอบ 1 แถว (ลบแถวทดสอบได้)
6. **Deploy > New deployment** → เลือกประเภท **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
7. กด Deploy แล้วคัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) — ลิงก์นี้คือลิงก์แบบสอบถามที่ส่งให้ผู้ตอบได้ทันที

> แก้โค้ดภายหลัง ต้องไปที่ **Deploy > Manage deployments > แก้ไข (ดินสอ) > Version: New version** ไม่เช่นนั้นลิงก์เดิมยังใช้โค้ดเก่า

## ถ้าต้องการโฮสต์หน้าเว็บที่อื่น (เช่น GitHub Pages)

แก้ค่า `GAS_WEB_APP_URL` ใน `index.html` เป็น Web app URL จากขั้นตอนที่ 7
หน้าเว็บจะส่งข้อมูลด้วย `fetch` ไปที่ `doPost` ใน `Code.gs`

## โครงสร้างข้อมูลในชีต (37 คอลัมน์)

วันเวลาที่บันทึก · การให้ความยินยอม · เพศ · อายุ · ตำแหน่ง · ระยะเวลาปฏิบัติงาน ·
คะแนนข้อ 1.1–5.1 (26 คอลัมน์ เป็นตัวเลข) · ข้อเสนอแนะ 1–5

ระบบไม่บันทึกคำตอบที่ส่งมาโดยไม่ได้กด "ยินยอม"

> ถ้าเคยสร้างแท็บ `ผลแบบสอบถาม` ไว้ก่อนแล้ว (จากโค้ดเวอร์ชันเก่า) ให้ลบหรือเปลี่ยนชื่อแท็บนั้นก่อน
> ระบบจะสร้างแท็บใหม่ที่มีคอลัมน์ "การให้ความยินยอม" ให้เอง ไม่เช่นนั้นคอลัมน์จะเลื่อนไม่ตรงหัวตาราง
